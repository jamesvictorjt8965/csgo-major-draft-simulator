## What This Tool Does

CS:GO Major Draft Simulator provides a browser-based workspace for creating and experimenting with lineups built around Major-style draft situations. Its workflow combines card draws, player choices, and role-conscious team placement, allowing different lineup concepts to be tested directly in the browser.

The simulator is delivered as a single-file HTML experience that can be opened locally, hosted, or embedded in a web workflow. Its planning tools include region and era filters, an organized team builder, and a simulation mode for trying out draft scenarios quickly.

## Feature Set

- Randomized, card-driven selection for draft-style sessions
- Player selection tools for creating potential candidate groups
- Role-aware placement to arrange players into a structured lineup
- Major simulation mode for exploring Major-style draft situations
- Region-based filtering for reducing the available choices
- Era filtering for concentrating on particular player periods
- Team builder flow for arranging and managing lineups
- Single-file front-end format for uncomplicated browser use

## Getting Started

1. Download or clone the repository files.
2. Launch the HTML file in a browser, or deploy it to a web host.
3. Select players to begin a lineup, then use the draft controls to run card draws and place selections.
